# 看板

随时打开本机看板，实时查看跨项目的在跑任务、`map` 批次进度、排队名次、改动文件、上下文告警与配置审计记录。

```sh
broco ui
broco ui --no-open
```

第一条自动打开浏览器，第二条只打印本地地址。看板记住端口并在 runner 重启后自动恢复。

## 四列状态与 `map` 批次

- **排队（Queued）**：在项目独立 FIFO 并发池中排队，显示当前队列位次。
- **进行中（Working）**：展示实时工具步骤、选中工人／模型／档位、分支与改动文件。
- **待验收（Review）**：工人已交回结果，等你检查 `diff` 或发起跨模型 `broco review`。
- **已完成（Done）**：经 `broco done 名字` 结单（列表折叠保留最近 50 张，支持搜索与批次／结果筛选）。

运行 `broco map` 批量分片时，看板顶部展示实时批次进度条，每张分片卡片带 `[index/count]` 徽标，详情抽屉支持一键切换兄弟分片。

## 检视证据与一键撤回

点开工单查看最终回复、多任务历史、按本机时区折叠的活动流（受 `BROCO_TZ`、`TZ` 或系统时区控制）、结果与故障横幅、60% 上下文窗口告警，以及写单者与跨模型审查者的关联链路。

终端中配合 `broco status`、`broco ls --active`、`broco show 名字 --compact`、`broco diff 名字`、`broco stats` 与 `broco watch` 使用。

点击页头**配置**查看检测状态、生效默认值、隐藏模型、[自定义 CLI 模板](custom-cli.md)，以及带一键**撤回**的配置审计日志。
